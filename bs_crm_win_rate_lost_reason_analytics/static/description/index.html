Feature overview

Gain complete visibility into sales pipeline drop-offs with structured reason categorization, enforced capture, and real-time executive analytics.

Reason Categorization

  • 7 standard categories: Pricing, Timing, Competitor, No Budget, No Response, Not a Fit, Other
  • Default native lost reasons pre-mapped to appropriate categories out of the box
  • New user-created reasons default to "Other" so data is never blank
  • Category column integrated directly into Lost Reasons list and form views
  • Automated post-install backfill categorizes pre-existing CRM records

Loss Capture & Context

  • Mandatory reason selection enforced whenever marking any opportunity lost
  • Consistent validation across both Kanban "Lost" and Form "Mark Lost" buttons
  • Dedicated Lost Note field stored directly on lead for qualitative context
  • Preserves native chatter closing feedback while isolating clean reporting data
  • Automatic cleanup of reason, category, and lost note when restoring a lead

Analytics Dashboard

  • Dedicated single-page dashboard at CRM > Reporting > Win Rate Dashboard
  • Executive KPI summary cards for Win Rate %, Won Deals, and Lost Deals
  • Interactive donut chart visualizing lost deal share by reason category
  • Salesperson win-rate comparison and stage drop-off funnel visualizations
  • Instant multi-filtering by Date Range, Sales Team, and Salesperson
  • Companion pivot and graph views for ad-hoc aggregation and Excel export
