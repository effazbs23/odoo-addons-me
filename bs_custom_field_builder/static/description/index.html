Feature overview

Everything you need to extend any Odoo model with custom fields without writing Python code or installing heavy development modules.

Guided 4-Step Wizard

  • Model search with safe internal-model blocklist
  • 8 supported field types (Text, Number, Date, Yes/No, Selection, Relation)
  • Auto-suggested technical naming (x_studio_*)
  • Clear explanations for Required and Form Visibility
  • Live notebook tab picker for precise field positioning
  • Visual placement preview before database commit

Audit Trail & Control

  • Centralized Custom Fields registry (Kanban and List)
  • Full Chatter audit log (mail.thread) for all changes
  • Instant Enable / Disable toggle on form views
  • Real-time data detection on target records
  • Guarded two-step confirmation for safe removal
  • Permanent history retained even after deletion

Native Architecture

  • Native Odoo metadata (ir.model.fields & ir.ui.view)
  • Zero server restart or module upgrade required
  • Fully searchable, filterable, and exportable fields
  • Forward-compatible with Odoo Studio upgrades
  • Automated email notifications via base.automation
  • Clean multi-company and user access security

Good to know

Fields, views, and notifications you create are native Odoo metadata, kept exactly like fields added through Odoo Studio: they stay fully functional even if this app is later uninstalled. Remove any fields you no longer want from the Custom Fields registry before uninstalling if you want a clean state.
