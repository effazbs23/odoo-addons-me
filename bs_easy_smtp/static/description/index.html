Odoo Module Technical / Email

Easy SMTP Setup

A guided wizard that picks the right SMTP host, port, and encryption for the provider you choose, lets you send a real test email before anything is saved, and turns cryptic SMTP failures into plain-language explanations — so outgoing email stops being a two-hour fight on day one.

Feature overview

Reachable from Settings without turning on developer mode — this is built for the admin who just needs email to work, not a sysadmin.

Provider Presets

  • Gmail, Google Workspace, Office 365, Zoho, SES, SendGrid, Mailgun, or Custom
  • Picking one auto-fills host, port, and encryption
  • Inline guidance on app passwords / API keys where needed
  • Custom leaves every field fully editable, no assumptions forced

Test Before You Trust It

  • Sends a real test email to an address you choose
  • Nothing is written to the database until you explicitly save
  • Failures are decoded into plain language with a suggested fix
  • Same decoder backs the native "Test Connection" button too

No Surprises

  • Saves as a normal, native Outgoing Mail Server record
  • Re-running the wizard updates that server, never duplicates it
  • Zero changes to how Odoo actually sends mail
  • No IMAP/POP, no OAuth flow, no bulk server management

Plain Language Everywhere, Even on the Native Button

The same decoder backs Odoo's own "Test Connection" button, so self-diagnosis after a change never shows a raw traceback.
