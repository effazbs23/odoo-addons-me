Odoo Module Technical / Email

Easy SMTP Setup

A guided wizard that picks the right SMTP host, port, and encryption for your chosen provider, lets you send a real test email before saving, and turns cryptic SMTP failures into plain-language explanations — so outgoing email configuration is fast, accurate, and foolproof.

Feature overview

Reachable directly from Settings without developer mode — built for administrators who need outgoing email working reliably without manual guesswork.

Provider Presets

  • Gmail, Google Workspace, Office 365, Zoho, SES, SendGrid, Mailgun, or Custom
  • Picking a provider auto-fills host, port, and encryption
  • Inline guidance on app passwords / API keys where needed
  • Custom option keeps all fields fully editable with no forced assumptions

Test Before You Save

  • Sends a real test email to an address you choose
  • Nothing is written to the database until you explicitly save
  • Decodes failures into plain-language explanations with suggested fixes
  • Shared decoder backs the native "Test Connection" button too

Native & Seamless

  • Saves directly as a native Outgoing Mail Server record
  • Re-running the wizard updates that server without duplicates
  • Zero changes to how Odoo actually delivers mail in background
  • Restores current server settings upon reopening for quick updates

What's included

8 pre-configured SMTP provider presets + Custom mode

Auto-fill for server host, port, and TLS/SSL encryption

Real test email verification without persisting dummy records

Actionable, plain-language error diagnostics and suggested fixes

Seamless creation and updating of native ir.mail_server records

Native Test Connection button enhancement with clear error messages

Accessible directly from Settings without enabling developer mode

In-place reconfiguration without duplicating existing mail servers
