Odoo Module Human Resources

HR Burnout & Retention Risk Dashboard

Proactively identify employee burnout risk by computing a per-employee index from overtime exposure and overdue task load — surfacing retention hazards before they become attrition events.

Overview

The HR Burnout & Retention Risk Dashboard gives people operations teams a data-driven early warning system for employee attrition. By combining 30-day overtime hours from timesheet entries with overdue project task counts, the module computes a single 0–100% burnout index per employee. The OWL-based retention heatmap surfaces high-risk individuals by name and department, enabling HR to intervene with targeted support before disengagement turns into resignation. It extends Odoo's native HR, timesheet, and project apps with zero disruption to existing workflows.

Highlights

Burnout Risk Index

Computed 0–100% score per employee combining overtime exposure and task backlog into a single risk metric.

30-Day Overtime Factor

Pulls the last 30 days of timesheet entries per employee, penalizing hours exceeding 160/month at a 2.5x factor.

Overdue Task Delay Factor

Counts open project tasks past deadline assigned to the employee; each overdue task adds 8 points, capped at 40.

Retention Heatmap UI

OWL dashboard renders a table of all employees with burnout index above 10%, showing name, department, and a red progress bar proportional to risk level.

Department-Level Visibility

Each row displays the employee's department, enabling HR to spot departmental concentration of burnout risk.

Real-Time Computation

Burnout index is recomputed on every read, not stored, ensuring the dashboard always reflects the latest timesheet and task data.
