Perishable Inventory Expiry Alerts

Proactive, cross-warehouse dashboard and alerts for lots nearing expiry — built on top of Odoo's own expiration-date tracking, not a parallel system.

Feature overview

Everything you need to catch near-expiry stock before it becomes a write-off, without changing how Odoo tracks lots and expiration dates.

Cross-Warehouse Dashboard

  • Every near-expiry lot across all locations, in one list
  • Grouped by product, warehouse, and days-to-expiry bucket
  • Expired / 0-7 / 8-30 / 31-90 / 90+ day buckets
  • Color-coded rows for expired and imminent stock
  • Pivot view for a warehouse × bucket quantity overview

Configurable Alerts

  • Per-category alert threshold (e.g. dairy at 7 days, dry goods at 30)
  • Global fallback default in Inventory settings
  • Daily cron creates an activity for the responsible user
  • No duplicate activities for the same lot
  • Suggested action: markdown/promotion or internal transfer

Write-off Assistant

  • One-click scrap wizard pre-filled from the dashboard row
  • Wraps Odoo's native scrap flow — no parallel stock model
  • Scrapped-value report by product and month
  • Recurring-loss visibility management actually wants

What's included

Expiry Dashboard grouped by product / warehouse / bucket

Per-category expiry alert threshold with a global default

Daily cron activity creation for responsible users, dedup'd per lot

Suggested-action flag: markdown/promotion or internal transfer

Expiry Write-off Assistant wrapping the native scrap flow

Scrapped-value report over time, by product and month

Built entirely on core lot/quant fields — no parallel data model

Works with standard manufacturing, sales and purchase flows

Good to know

Requires the core product_expiry module (adds expiration dates to lots/serials) and works in Odoo Community — no Enterprise dependency. All alerting reads and writes the same expiration_date / alert_date fields Odoo already uses, so nothing about your existing manufacturing, sales or purchase flows changes.
