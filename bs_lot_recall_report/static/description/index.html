Odoo Module Inventory Traceability

Lot Recall Report

One-click recall report tracing a lot/serial number to every customer, order, and shipment it touched.

Feature overview

Generate an audit-ready recall report for any lot or serial number directly from the Inventory app, in one click.

Forward trace

  • Every customer, sales order and delivery that received the lot
  • Affected quantity and delivery dates at a glance
  • Built from the same stock move data as Inventory > Traceability

Backward trace

  • The vendor(s) and purchase order(s) that supplied the lot
  • The manufacturing order that produced it, plus one level of component lots consumed
  • Full upstream picture for root-cause investigation

Batch mode & export

  • Trace several lots at once for an entire production run
  • Print-ready PDF export for regulators and auditors
  • XLSX export with separate forward/backward trace sheets

What's included

Recall Report record with a Draft → Generated workflow

Forward and backward trace dashboards with affected-quantity stats

"Fully traceable" indicator once every movement has been identified

One-click "Recall Report" smart button on every lot/serial number

Print-ready recall report PDF

XLSX export with Forward Trace / Backward Trace sheets

Searchable recall log for compliance and audit evidence

Dedicated access groups (User / Manager) and multi-company rule
