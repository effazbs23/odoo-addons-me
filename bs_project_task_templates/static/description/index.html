Project Stage Task Templates

Auto-create predefined checklist tasks whenever a project or task enters a configured stage — with dynamic placeholders, smart assignee resolution, and full audit tracking.

Feature overview

Standardize repeatable project workflows, QA cycles, and onboarding checklists with zero manual re-entry and complete execution control.

Template Builder & Dynamic Tokens

  • Define reusable template tasks per project stage or task stage
  • Dynamic title tokens (e.g. Kickoff with {{partner_name}})
  • Flexible assignee rules: Fixed user, Project Manager, or Record Assignee
  • Relative deadline calculation (N days after stage entry)
  • Custom priority levels, descriptions, and tags per template

Automation & Idempotency

  • Instant automated task creation on project or task stage change
  • Configurable trigger scopes: Project-level, Task-level, or both
  • 3-tier Idempotency: Always re-create, First-time only, or Confirm
  • Interactive confirmation wizard to review and deselect tasks
  • Seamless execution across single and bulk stage transitions

Audit Trail & Management

  • Auto-generated tasks tagged for clear visibility and filtering
  • Direct traceability link back to originating stage template
  • Automated chatter logging referencing the triggering record
  • Smart buttons on stage settings for instant template overview
  • Per-project toggle to enable or disable automated templates

What's included

Stage Task Template Builder for project and task stages

Dynamic placeholder token resolution in task titles

Smart assignee assignment (Fixed, PM, or Trigger Assignee)

Relative deadline computation (N days offset from entry)

Independent project-level and task-level trigger scopes

3-mode idempotency control (Always, First-time, Confirm)

Interactive wizard for previewing and selecting tasks

Complete audit trail with chatter logs and template links

Dedicated auto-generated task tracking tags

Stage settings smart buttons and per-project automation controls
