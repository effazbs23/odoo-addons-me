Purchase Return Management

Manage vendor (purchase) returns end to end — from a return request anchored on a purchase order, through the return-to-vendor shipment, to the matching vendor credit note — with lot/serial precision, location-aware stock checks, and a controlled approval workflow.

Key Features

Core Return Workflow:
Vendor return requests anchored directly on a purchase order, with the vendor auto-filled. Features a 5-stage approval workflow (Draft → Submitted → Approved → Processing → Done) plus Cancelled and Reset to Draft. Manager-only approval enforces segregation of duties. Supports optional reference documents (vendor bill and incoming receipt) and per-request reason, priority, responsible user, expected date, and company.
Automatic Return-Line Generation:
Return lines are generated automatically from PO goods lines in product UOM. Lot/serial aware generation ensures users only claim lots actually received. Returnable quantities are capped by real on-hand stock at the chosen source location, with serial products constrained to 0 or 1. Live per-line visibility covers ordered, received, billed, on-hand, and returnable quantities.
Location-Aware Returns:
Ship returns from wherever goods are located (main stock, QC, or rejection area), defaulting to receipt destination. Automatically re-generates and re-caps quantities when source location changes, and blocks processing with clear guidance if source location inventory is insufficient.
Return-to-Vendor Shipment:
Generates a return delivery picking from source location to vendor supplier location using configured operation types. Chained to original receipt moves (newest first) for full traceability, valuation accuracy, and automatic PO received quantity adjustment upon validation. Auto-completes request to Done once fully shipped.
Vendor Credit Note / Refund Engine:
Automatically drafts partial vendor credit notes. Absorbs unbilled capacity into future billing and refunds only previously billed amounts with chatter log breakdowns. Target bill allocation accounts for existing draft/posted refunds, while netting out concurrency across open requests on the same PO line/lot.
Navigation & Smart Buttons:
Seamless routing with smart buttons on the return request to view picking operations and vendor credit notes. Convenient return count stat buttons added to Purchase Order, Vendor Bill, and Incoming Receipt forms.
Reporting & Analysis:
SQL-backed Purchase Return Analysis report featuring graph, pivot, and list views by vendor, product, PO, lot, status, reason, and amount. Includes printable QWeb PDF return requests, search filters, Kanban board, and custom group-by options.
Security & Multi-Company Isolation:
Dedicated Return User and Return Manager security groups with segregation of duties. Enforces record rules for personal vs. managerial access and complete multi-company data isolation on requests and analytics. Restricts vendor selection to valid suppliers.
Automation & Configuration:
Automated sequence numbering (VRET… prefix), integrated email notification templates for submission and approval, and complete mail thread chatter and activity tracking on every request.

Screenshots & User Guide Workflow

1. Navigate to Inventory Module

Access the Inventory application from the main Odoo app dashboard to prepare tracked products.

2. Select Products Menu

Click on the Products menu in the navigation top bar to manage catalog items.

3. Create New Product

Click on the New button to open the product creation form.

4. Configure Product & Inventory Tracking

Enter product name (e.g., Red Potato), set cost price, and check Track Inventory to enable stock control.

5. Configure Security Access Rights

In Settings > Users & Companies, assign user privileges to Return User or Return Manager roles.

6. Access Purchase Module

Open the Purchase application to initiate vendor purchase orders.

7. Manage Vendor Contacts

Navigate to Purchase > Orders > Vendors and click New to add or select a supplier.

8. Create & Confirm Purchase Order

Create a Purchase Order with products and quantities, then click Confirm Order.

9. Receive Goods on Purchase Order

Click Receive Products to record incoming inventory for the purchase order.

10. Validate Incoming Receipt

Validate the receipt operation (WH/IN) to record received stock quantities into the warehouse location.

11. Open Return Application

Click on the Return app icon from the main menu launcher to begin managing vendor returns.

12. Purchase Return Requests Dashboard

View all existing return requests or click New to create a new return authorization.

13. Select Vendor & Purchase Order

Select the vendor and purchase order to automatically generate location-aware return lines.

14. Optional Bill & Receipt Linkage

Optionally select specific reference vendor bills or receipts for precise refund calculation.

15. Specify Return Quantities & Submit

Enter the requested return quantities (capped automatically by stock on hand) and click Submit.

16. Approval Process & Execution Tracking

Track full approval progression (Draft → Submitted → Approved → Processing → Done) with chatter updates and access linked stock pickings via smart buttons.
