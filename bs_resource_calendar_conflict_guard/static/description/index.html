Feature overview

A guard rail on top of the native Odoo Calendar, checking every create and edit for overlapping bookings on the same employee or meeting room / equipment resource.

Reliable Overlap Detection

  • Checks both internal attendees and booked meeting rooms/equipment
  • Correctly excludes an event's own prior state while it's being edited
  • Ignores declined attendees and cancelled events
  • All-day events block the full calendar day, not just the 8:00-18:00 display window

Buffers & Next Slot

  • Optional turnaround buffer required before/after every booking
  • Defaults to zero (exact overlap only) so existing schedules are unaffected on install
  • Every block message includes the next open slot for that resource
  • Independent toggles for checking employees and/or resources

Deliberate Override, Always Logged

  • Permission-gated "Can Override Booking Conflicts" group
  • Explicit "Review Conflict" → "Book Anyway" confirmation, never a silent bypass
  • Every blocked AND every overridden attempt is written to a durable audit log
  • Conflict Log records survive even when the booking itself is rejected

What’s included

Booked Resources field added to the Calendar Event form

Create/write validation hook naming the specific conflicting resource

Override confirmation wizard ("Review Conflict")

Dedicated override security group

Conflict Guard settings under Settings > Calendar

bs.calendar.conflict.log audit trail model

Next-available-slot suggestion engine

Zero changes to native calendar behavior when the guard is switched off
