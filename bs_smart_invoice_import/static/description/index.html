Odoo Module Sales / Purchase

Smart Invoice Import

Turn pasted text or an invoice photo/PDF into Sale and Purchase order lines in one shot — paste or upload, let smart product matching find the right items, review everything in a preview grid, then confirm.

Dependencies

Sales (sale) Purchase (purchase) Settings (base_setup)

About "Upload Invoice" (AI extraction): this mode calls an OpenAI-compatible LLM API of your choice (OpenAI, Groq, Azure OpenAI, a self-hosted server, ...), which you configure yourself under Settings with your own account and API key. That API usage is billed directly by its provider, separate from this module's price. The "Paste Text" mode needs no such account and has no external cost.
