Supply Chain Lead Time & Bottleneck Dashboard

Measure vendor delivery precision by comparing planned purchase order dates against actual picking completion dates, surfacing the average arrival latency deviation per supplier.

Overview

The Supply Chain Lead Time & Bottleneck Dashboard gives procurement and logistics teams a vendor performance scoreboard, ranking every supplier by how many days their deliveries slip past the planned date. For each completed purchase order, the module compares the planned date against the actual picking completion date and computes a per-supplier average delay index. The OWL-based slippage table surfaces the worst-performing vendors first, with color-coded severity badges that make bottleneck triage instantaneous. This extends Odoo's purchase and stock apps with zero disruption to existing procurement workflows.

Highlights

Vendor Delay Index

Computed float field on res.partner measuring average days late across all completed purchase orders for that supplier.

Planned vs. Actual Comparison

For each done PO, compares date_planned against the picking date_done to calculate slip in days; only positive delays are counted.

Top-Worst Vendor Sorting

Dashboard pre-sorts vendors by delay index descending, so the worst-performing suppliers appear first for immediate attention.

Badge Severity Indicator

Late arrivals are tagged with a rounded-pill badge: red for more than 3 days late, yellow for 3 days or fewer, with "N Days Late" text.

Supplier Slippage Table

OWL dashboard renders a hoverable table listing all vendors ranked by delay index descending with supplier name and color-coded badges.

Per-Supplier Aggregation

Averages the slip across all valid pickings per partner, giving a single Fulfillment Delay Variance number per supplier.
