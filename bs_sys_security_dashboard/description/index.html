Odoo Module Technical Security

Server Health & Security Command Center

Track active user sessions, display IP addresses and last activity timestamps, and terminate rogue sessions on demand — all from a real-time security telemetry dashboard.

Overview

The Server Health & Security Command Center gives system administrators real-time visibility into every active Odoo session. A dedicated session log model tracks user, session ID, IP address, and last activity timestamp, while the OWL-based live session table displays all logged sessions with monospace IP addresses and one-click termination. When a session is killed, the record is deleted from the database and purged from Odoo's session store, immediately logging out the target user. ACL rules ensure read-only access for all internal users and full CRUD for system administrators, making it a zero-config security layer for any Odoo deployment.

Highlights

Session Termination

One-click kill deletes the session record from the database and purges it from Odoo's session store, logging out the target user instantly.

Live Session Table

OWL dashboard renders a hoverable table of all logged sessions showing user, IP address in monospace, last activity, and a red Terminate button per row.

Access Control

ACL rules grant read-only access to all internal users and full CRUD to system administrators, enforcing the principle of least privilege.

IP Address Visibility

Each session row displays the connecting IP in a code block for easy identification of suspicious origins.

Notification Feedback

Uses Odoo's notification service to display a "Session terminated." success message upon successful kill with instant UI refresh.

Session Log Model

New bs.session.log model tracking user_id, session_id, IP address, and last_activity timestamp per active session.
