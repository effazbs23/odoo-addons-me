Overview

Splitting freight, duty and customs charges across the lines of a receipt is one of the most fiddly, error-prone parts of landed cost accounting — Odoo already lets you enter the split manually, but picking a rate and typing it in for every line, every shipment, adds up fast and is easy to get wrong. Landed Cost Auto-Allocator adds a single "Auto-Allocate" button to the Landed Cost record: it suggests the right allocation method per cost line from reusable rule templates (e.g. "always allocate DHL freight by weight"), checks that every affected product has the weight or volume data a weight/volume split needs, then lets Odoo's own computation populate the valuation adjustment lines — nothing about the underlying accounting flow changes. Freight, duty and customs can each use a different method on the very same record, an Allocation Preview shows quantity, weight, volume and value per line before you post, and a plain-language audit trail records exactly how each amount was calculated for finance review. Built for purchasing, logistics and inventory teams who process import shipments with multi-component landed costs on a regular basis.

Audit-ready formulas, not just numbers

Every allocated line keeps a plain-language record of exactly how its share was worked out — the totals, the rate, and the formula applied — so finance can review a split without reverse-engineering it from the numbers alone.

  • One formula template per allocation method (equal, quantity, value, weight, volume)
  • Stored per line, so mixed-method records stay fully explainable
  • Open from the landed cost form with a single click

Rules that remember your vendors

"Always allocate DHL freight by weight" becomes a saved rule instead of a habit someone has to remember. Auto-Allocate matches the best rule for each cost line — vendor and cost type, cost type alone, or vendor alone, in that order — so new shipments from the same vendor default correctly from the start.

  • One rule set, reused across every future landed cost
  • Clear, documented priority order when several rules could match
  • Managed from Inventory > Configuration like any other setting
