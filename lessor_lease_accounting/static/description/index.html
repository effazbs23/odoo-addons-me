Lessor Lease Accounting

Automated Accounting for Lessor Lease Contracts

Odoo 18.0 Automated Accounting Hire-Purchase Journal Entries

Overview

The Lessor Lease Accounting module extends the Lessor Lease Scheduling module with comprehensive accounting automation. It handles the complete accounting lifecycle of lessor lease contracts using the Gross Method (Hire-Purchase) accounting standard, from initial recognition to periodic accounting entries. Support for Net Method (IFRS 16) is currently under development.

⚠️ Important: This module requires the Lessor Lease Scheduling module to be installed first.

Key Features

💰 Down Payment Invoicing

Automatically generate and manage down payment invoices for lease contracts with proper GL account linkage.

📝 Initial Recognition

Create initial recognition journal entries using the Gross Method (Hire-Purchase) accounting standard with proper asset and unearned interest recognition.

⚙️ Periodic Automation

Automated periodic accounting entries through scheduled cron jobs for interest income and principal recognition.

🏦 GL Account Configuration

Flexible GL account configuration in accounting settings for all lease-related transactions.

📊 Complete Lifecycle

Handle the entire lease accounting lifecycle from inception to contract closure.

🎯 Dashboard Analytics

Comprehensive dashboard with lease analytics, financial summaries, and key performance indicators.

Functionality

Down Payment Processing

  • Automatic down payment invoice generation
  • Integration with Odoo accounting workflow
  • Support for partial and full down payments
  • Advance rent handling
  • Automatic GL account assignment

Initial Recognition Entries

  • Gross Method (Hire-Purchase) initial recognition
  • Asset and liability setup
  • Lease receivable recognition
  • Unearned interest recognition for Hire-Purchase method

Periodic Accounting

  • Automated monthly/periodic accounting entries
  • Interest income recognition
  • Principal reduction tracking
  • Lease receivable updates
  • Scheduled cron job execution

Dashboard & Reporting

  • Lease portfolio overview
  • Financial KPIs and metrics
  • Contract status tracking
  • Revenue recognition analytics
  • Drill-down capabilities

Configuration

GL Account Setup

Configure GL accounts through Accounting → Configuration → Settings → Lessor Lease Accounting:

  • Lease Receivable Account
  • Interest Income Account
  • Down Payment/Advance Rent Account
  • Unearned Interest Account (for Hire-Purchase method)
  • Asset Account

Automated Jobs

The module includes scheduled actions for:

  • Periodic accounting entry generation
  • Interest income recognition
  • Automatic posting based on schedule dates
💡 Tip: Review and adjust the cron job schedule in Settings → Technical → Scheduled Actions to match your accounting period requirements.

Usage Workflow

  1. Create Lease Contract: Set up the lease contract in Lessor Lease Scheduling
  2. Generate Schedule: Create the amortization schedule
  3. Process Down Payment: Generate and confirm down payment invoice
  4. Initial Recognition: Create initial recognition journal entry
  5. Activate Contract: Change contract state to active
  6. Periodic Accounting: Automated periodic entries will be created by scheduled actions
  7. Monitor Dashboard: Track contract performance and financials
