Odoo 18.0 Finance Lease Hire-Purchase Multi-Currency

Overview

The Lessor Lease Scheduling module provides comprehensive lease contract management for lessors, featuring automated amortization schedule generation using the Gross Method (Hire-Purchase). This module delivers precise financial calculations that match Excel models, ensuring accuracy and reliability in your lease management operations. Support for Net Method (IFRS 16) is currently under development.

Key Features

🏢 Contract Management

Create and manage finance lease contracts with complete lifecycle tracking from draft to closed status.

📊 Automated Scheduling

Generate amortization schedules automatically with precise financial calculations matching Excel models.

💼 Hire-Purchase Method

Complete support for Gross Method (Hire-Purchase) lease accounting with accurate interest and principal calculations.

💱 Multi-Currency

Handle lease contracts in multiple currencies with built-in currency conversion support.

🔗 Asset Integration

Seamlessly integrate with asset management for complete visibility of leased assets.

📈 Financial Precision

Accurate calculation of interest, principal, and lease receivables with detailed breakdowns.

Functionality

Lease Contract Creation

  • Define lease terms including start date, duration, and payment frequency
  • Configure down payment and advance rent details
  • Set up residual value and purchase options
  • Specify lessees and related parties
  • Link to assets being leased

Schedule Generation

  • Automatic amortization schedule generation based on lease terms
  • Detailed breakdown of each payment period
  • Calculation of opening balance, interest, principal, and closing balance
  • Gross Method (Hire-Purchase) calculations with unearned interest tracking
  • Re-generate schedules when contract terms change

Reporting & Analytics

  • Comprehensive lease schedule views
  • Financial summaries and totals
  • Export capabilities for external analysis
  • Search and filter options for efficient data management

Configuration

After installation, configure the module through:

  • Navigate to Accounting → Configuration → Lessor Lease → Contracts
  • Set up your first lease contract with all required parameters
  • Generate the amortization schedule
  • Review and confirm the schedule details
