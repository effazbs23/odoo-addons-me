Overview

When a lot or serial number turns out to be defective, the clock starts running: quality, compliance, and sales teams all need the same answer immediately — who has this stock, and where did it come from? Lot Recall Report turns that scramble into a single click from any lot or serial number record. It walks Odoo's own traceability graph (the same stock move data behind Inventory > Traceability) to build a forward trace of every customer, sales order and delivery that received the lot, and a backward trace of the vendor, purchase order, or manufacturing order that produced it. Reports can cover a single lot or an entire production batch at once, and every report generated is saved to a searchable recall log for audit and compliance evidence. Built for regulated industries — pharmaceuticals, food, chemicals, electronics — where a documented, repeatable recall procedure matters as much as the recall itself.

Features

01
One-click recall wizard
Launched directly from a lot/serial number (stock.lot) with a single "Generate Recall Report" action.
02
Forward trace
Every sales order, delivery, and customer that received stock containing the selected lot, with quantities and dates.
03
Backward trace
The originating purchase order or manufacturing order, and the vendor/component lot(s), that fed into the selected lot.
04
Multi-lot batch mode
Select several lots at once — e.g. an entire production run — and generate one consolidated report.
05
Print-ready PDF & XLSX export
Company-branded output with the generation date/time and the user who ran it.
06
Recall log
Every generated report is stored and searchable later for audit and compliance purposes.
07
Customer notification helper
A pre-filled list of affected customer emails/contacts for the sales team to follow up with (does not auto-send).

Built on Odoo's own traceability graph

Instead of maintaining a second, parallel record of stock movements that can drift out of sync with reality, Lot Recall Report reads directly from the same stock.move.line data that powers Inventory > Traceability. The value-add is entirely in the report format, the batch/audit layer, and the one-click workflow — not a competing tracking system.

  • No duplicate data to keep in sync with core Inventory
  • Works with whatever traceability data already exists in your database
  • Community Edition compatible — no Enterprise-only dependency
