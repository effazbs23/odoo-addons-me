Theme Kingdom
=============

Kingdom is a premium Odoo 19 eCommerce website theme for megastores and multi-category online shops.

Installation
------------

1. Copy the ``theme_kingdom`` module into your Odoo addons path.
2. Update the Apps list and install **Theme Kingdom**.
3. Go to **Website → Site → Themes** and select Kingdom.
4. Edit the homepage with the Website Builder and add Kingdom snippets.

Dependencies
------------

- website
- website_sale
- website_sale_wishlist
- website_sale_loyalty
- website_blog
- product

Deal of the Day
---------------

Configure offers under **Website → Configuration → Deals of the Day**:

- Link an Odoo **Pricelist** (Sales → Products → Pricelists) or **Promotion** program.
- Set **Offer Start** and **Offer End** dates; a scheduled action updates the homepage automatically.
- Use **Add Multiple Products** on the pricelist to add many products at once.

Snippets
--------

Available drag-and-drop blocks include Hero Slider, Category Slider, Deal of the Day,
Featured Products, Best Sale Products, Promo Banners, Blog News, Brands,
Service Highlights, and Product Carousel.
