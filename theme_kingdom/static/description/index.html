Setup

Configuration

Website → Configuration → Deals of the Day, Featured Products, Best Sale, Brands, and Product Tabs. Use Sales → Pricelists and eCommerce → Promotions for offer pricing.

Deploy

Installation

Install Theme Kingdom, apply it to your website, then update after upgrades (-u theme_kingdom). Add Kingdom snippets from the Website Builder.
