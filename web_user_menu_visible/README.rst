This module extends the web user menu to always show the username in the top bar of Odoo UI,
regardless of debug mode.

**Table of contents**

.. contents::
   :local:

Features
========

* Always displays the username in the top bar
* Database name is still only shown in debug mode
* Maintains the same styling and layout as the default Odoo interface

Usage
=====

After installing the module, the username will automatically be displayed in the top bar
at all times, not just in debug mode.
