Web User Menu Visible

Keep the logged-in user name visible in the Odoo top bar at all times. This lightweight web module removes the default debug-only limitation and makes the user identity consistently visible without changing the standard user-menu behavior.
LGPL-3 Depends: web No Configuration Needed
Always Show User Name The user name remains visible in the top navigation bar, even when debug mode is off.
Keep Native Layout The module follows Odoo's default top-bar structure and preserves the standard interface style.
Minimal Frontend Change A focused web template override delivers the feature without extra menus, settings, or complexity.

Overview

By default, Odoo shows the user name in the top bar only in debug mode. Web User Menu Visible adjusts that behavior so users can always see which account is currently active. This is especially useful in shared environments, support sessions, training instances, and multi-user back-office teams.

Key Features

Consistent User Identity

  • Always displays the logged-in user name in the top bar.
  • Improves clarity when multiple users work in the same environment.
  • Reduces confusion during screen sharing or user support sessions.

Standard Odoo Experience

  • Keeps the default Odoo user-menu location and overall look.
  • Database name remains limited to debug mode.
  • No new settings or menus are introduced.

How It Works

Default Odoo Behavior

In standard Odoo, the top-bar user name is tied to debug mode visibility. When debug mode is off, the name is hidden and only the avatar remains visible.

Module Behavior

This module updates the web user-menu template so the user name remains visible at all times, while preserving the existing debug-only display of the database name.

Usage: install the module and refresh the backend interface.
Result: the logged-in user name is always visible in the top bar.
Configuration: none
